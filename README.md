# Bushido — Libro II

Segunda parte de *Bushido: El Camino del Guerrero* (Javier Felipe Flórez Quintero).

El Libro I sigue a Musashi a través de las veintiuna distinciones hasta que cruza el portal de vuelta a su tierra.
El Libro II se centra en **el maestro**: qué pasa con él, con el bosque y con Yui después de que Musashi se va.

## Archivos

- `libro-2/biblia-libro-1.md` — continuidad del Libro I: personajes, reglas del bosque, objetos y todas las pistas sobre el maestro, capítulo por capítulo.
- `libro-2/propuesta.md` — premisa, estructura propuesta y decisiones pendientes para el Libro II.
